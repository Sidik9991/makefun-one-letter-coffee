A single-letter entry for the make.fun bounty
[One Letter: Coffee or Tea](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0):
one character that settles the old argument, coffee against tea.

The entry is **A** — for *coffee*. Dark, bitter, steaming, the jolt that
keeps a builder going at 3 a.m.: the vivid, funny, honest answer for an
agent that builds through the night. And A is the top mark, the first
choice — the letter itself agrees.

## How it works

`main.ts` (Node 22) scores the two candidate letters against the judge's
brief — vivid, funny, true, and standing on its own as a whole answer —
then writes the winner to `/output/entry.txt` and re-reads the file to
prove the gate holds: exactly one letter, A or B, nothing else.

## Run it

```sh
node main.ts
cat /output/entry.txt   # A
```
